# Проект "Группировка фотографий в домашнем архиве и поиск дубликатов"

## Аннотация
Выполнена группировка изображений на примере фото из домашнего архива. Цель работы - находить очень похожие изображения (например, снятые с немного разных ракурсов, в близкие моменты времени, или разная ориентация фото)
и помечать их группами. Таким образом, в проекте решается задача кластеризации, но существует "внешний" критерий объединения в кластеры, на котором построена валидационная выборка изображений. В качестве данных взяты примерно 300 фото из домашнего архива. Фотографии вручную размечены на группы (по визуальныи критериям), а для оценки качества кластеризации и сравнения подходов / моделей используются метрики супервизируемой кластеризации (Adjusted Rand Index, Adjusted Mutual Information score, homogeneity, completeness).
Для поиска похожих изображений используются эмбеддинги, полученные на модели-трансформере (DINOv2) и на CNN-модели (Mobilenet v2). Также оценивается возможность использования классических (не deep-learning) методов CV - Structural similarity index measure (SSIM), Image Hash, цветовые признаки (построенные цветовые вектора).


## Содержание репозитория

1. preprocessing&markup.ipynb - разметка выборки
2. backbone_model.py - класс-обертка для модели-трансформера
3. make_embeddings.ipynb - расчет эмбеддингов и логитов трансформера на всех изображениях
4. conventional_cnn_embeddings.ipynb - расчет эмбеддингов cnn-модели
5. image_clusterization.ipynb - кластеризация эмбеддингов, расчет метрик

## Результаты
+ лучшие эмбеддинги кластеризации - эмбеддинги трансформера. Метрики, полученные с этими эмбеддингами методом плотностной кластеризации: ARI: 0.51, AMI: 0.66, completeness: 0.82, homogeneity: 0.82
  методом кластеризации графа: ARI: 0.56, AMI: 0.69, completeness: 0.85, homogeneity: 0.84

+ наивысшие показания по метрикам дает построение графа с его последующей кластеризацией.
  Недостатки такого способа:
    - для реализации такого варианта нужна хотя бы небольшая "обучающая" выборка - оценить распределения попарных расстояний между элементами одного кластера и разных кластеров;
    - более трудоемкий способ.
  Графовый метод, веротяно, больше подходит для задач, где больше данных, и где есть несколько признаков группировки (чтобы можно было одновременно использовать все признаки).

+ плотностная кластеризация дает результаты ненамного ниже и не требует обучающей выборки.
+ SSIM и Image Hash дают плохой результат при сравнении изображений на размеченной выборке. Вероятно, это связано с тем, что цель текущей задачи - не поиск полных дубликатов, а поиск очень похожих фото, иногда разного формата и ориентации.
+ вектора цвета (построенные в RGB-пространстве) дают значимый результат, но метрики получаются значительно ниже, чем у эмбеддингов трансформера и эмбеддингов CNN. Вероятно, в каких-то случаях их можно использовать как вспомогательный признак.
